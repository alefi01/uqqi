# Превью премиум-дизайнов (MP4-лупы + постеры)

Сюда кладутся ролики-превью для галереи дизайнов в ЛК (пикер при создании
сайта + экран «Дизайн»). Пока файла нет — карточка показывает плейсхолдер
с названием дизайна (video.onError в `static/lk/*.jsx`), ничего не ломается.

## Что нужно для каждого премиум-дизайна

На каждый ключ из `app/designs.py` (tier=pro) — два файла:

- `<key>.mp4` — короткий немой луп (5–10 c), запись прокрутки витрины.
  Без звука, зациклен. Рекомендация: ширина ~800px, H.264, ≤2–3 МБ.
- `<key>.jpg` — постер (первый кадр), показывается пока грузится видео.

Ключи (8 шт.): `noir`, `editorial`, `bloom`, `clarity`, `garage`,
`atelier`, `hearth`, `forge`.

Пути в API отдаются автоматически (`app/designs.py: public_list`):
`/static/designs/<key>.mp4` и `/static/designs/<key>.jpg`.

## Как записать

Открой любой сайт в нужном дизайне через живой предпросмотр:
`https://<slug>.uqqi.ru/?variant=<key>` (работает в обход Pro-гейта, без
учёта визита). Запиши прокрутку сверху вниз, обрежь до лупа, сконвертируй
в mp4 без звука. Положи файлы сюда, задеплой — карточки в ЛК подхватят
их сами (имя = ключ дизайна).
